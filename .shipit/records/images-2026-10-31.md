# Images and Trivy, 2026-10-31

Built locally with `docker buildx` (Docker Desktop 28.3.3, containerd image
store, builder `desktop-linux`) for `linux/arm64` and `linux/amd64`, loaded,
not pushed. Tags: `ghcr.io/vandatnguyen919/playground-{gateway,api,keycloak}:latest`

Gateway app layers on top of the JRE: SPA 303 kB, application 193 kB, the
rest is the dependencies layer.

Build times (warm Gradle and npm caches): gateway 357 s first build, about
20 s after a metadata change; api 129 s; keycloak 1046 s, almost all of it
the arm64 `kc.sh build` under QEMU.

QEMU for arm64 was not registered in Docker Desktop on this machine (arm64
`RUN` failed with `exec format error`). Registered with
`docker run --privileged --rm tonistiigi/binfmt --install arm64`; it resets
when Docker Desktop restarts. Gateway and api built for arm64 without it,
since their final stages only copy.

High and Critical, with fixed versions:

  CVE-2026-65905, CVE-2026-68525 (Critical), fixed in 11.0.25.

  3.1.5, CVE-2026-89407, CVE-2026-89425, CVE-2026-68497, CVE-2026-91776,
  CVE-2026-91777, fixed in 3.1.7.

  fixed in 2.21.7.
- keycloak (upstream base image): `ca-certificates` 2025.2.80 CVE-2026-114406
  (Critical, fixed in 2026.2.92); `java-21-openjdk-headless` 21.0.12.1.1
  CVE-2026-91403 and CVE-2026-91415 (no fix yet); `guava` 33.6.0

All Java findings in gateway and api are versions managed by the Spring Boot
4.1.1 BOM. Not changed here: see `.shipit/open.md`.
